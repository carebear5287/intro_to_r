Install R

(I’m going to assume you’re using Windows.)

First, go here: https://cran.r-project.org/mirrors.html

Choose a CRAN mirror to download from. It says to choose one close to you, so I use the one at Case. (I don’t think it really matters that much though?)

Once the installer is downloaded, then just go through the setup process. You probably don’t need to really change anything.

Install RStudio

Go to https://posit.co/downloads, run the installer, and you should be able to just use the defaults there, too.

Once RStudio is set up, open it.

Using RStudio

When you first open it, the console should be on the left of the screen and should show the R version that you’re running.

You can run R commands there one line at a time, but generally it’s easier to work from a script. Go to New File (in the top left) and add an R Script. R scripts will be most of what I will have saved in this repository.

If you type some commands in the script, highlight them, and then run them, the output will show up in the console below.
